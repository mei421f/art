# Artosphere — سایت برندینگ کوروش آرزومند

سایت با **Next.js 14 (App Router)** + **TypeScript** + **Tailwind CSS** + **Prisma** ساخته شده.
دو زبانه فارسی/انگلیسی (`/fa` و `/en`) با تعویض جهت RTL/LTR خودکار.
دیتابیس فقط برای دو چیز استفاده می‌شه: نگه‌داری پروژه‌های صفحه Work و ذخیره پیام‌های فرم تماس. رنگ، فونت، لوگو و تصاویر رو خودت جایگزین می‌کنی (فایل‌های مشخص‌شده پایین).

## ساختار صفحات

```
/fa یا /en
  ├── /            Home
  ├── /work         Work — از دیتابیس خونده می‌شه
  ├── /services     Services
  ├── /about        About
  ├── /process      Process
  └── /contact      Contact — فرم، به دیتابیس ذخیره می‌شه
```

## ۱) نصب و اجرای لوکال

```bash
npm install
cp .env.example .env
# مقدار DATABASE_URL رو داخل .env بذار (مرحله بعد)
npm run db:push     # ساخت جدول‌ها روی دیتابیس
npm run seed        # اضافه‌کردن پروژه‌های ROVA و KOVA
npm run dev
```

سایت روی `http://localhost:3000` بالا میاد و به `/fa` ریدایرکت می‌شه.

## ۲) ساخت دیتابیس رایگان (Neon Postgres)

Railway دیگه پلن رایگان دائمی نداره، برای همین دیتابیس رو جدا و رایگان می‌گیریم و فقط آدرسش رو به سایت روی Railway می‌دیم.

1. برو به **[neon.tech](https://neon.tech)** و با گیت‌هاب/گوگل ثبت‌نام کن (پلن Free همیشگیه، نیاز به کارت نیست).
2. یک پروژه جدید بساز (مثلاً به اسم `artosphere`).
3. از داشبورد پروژه، **Connection string** رو کپی کن — چیزی شبیه این:
   ```
   postgresql://user:password@ep-xxxx-pooler.eu-central-1.aws.neon.tech/neondb?sslmode=require
   ```
4. همین رشته رو به‌عنوان `DATABASE_URL` هم توی `.env` لوکال و هم توی تنظیمات Railway (مرحله بعد) قرار بده.

> جایگزین‌های دیگه اگه خواستی: [supabase.com](https://supabase.com) (پلن رایگان) یا [aiven.io](https://aiven.io). فقط کافیه یک connection string پستگرس بدن؛ چیز دیگه‌ای توی کد عوض نمی‌شه.

## ۳) دیپلوی روی Railway

1. کد رو به یک ریپازیتوری گیت‌هاب پوش کن.
2. توی [railway.app](https://railway.app) یک پروژه جدید بساز → **Deploy from GitHub repo** → همین ریپو رو انتخاب کن.
3. توی تب **Variables** سرویس، این‌ها رو اضافه کن:
   - `DATABASE_URL` → همون رشته‌ای که از Neon گرفتی
   - `ADMIN_TOKEN` → یک رشته دلخواه و محرمانه (برای دیدن پیام‌های تماس)
4. Railway به‌صورت خودکار Next.js رو تشخیص می‌ده، `npm install` و `npm run build` رو اجرا می‌کنه و با `npm run start` بالا میاره (تنظیمات توی `railway.json`).
5. بعد از اولین دیپلوی موفق، یک بار از لوکال (یا با Railway CLI) این دو دستور رو با همون `DATABASE_URL` پروداکشن اجرا کن تا جدول‌ها ساخته و سید بشن:
   ```bash
   npm run db:push
   npm run seed
   ```
6. دامنه‌ات (`artospherebranding.ir`) رو توی تب **Settings → Domains** به سرویس Railway وصل کن (رکورد CNAME که Railway می‌ده رو توی DNS دامنه ثبت کن).

## ۴) پنل ادمین

آدرس: `https://your-domain.com/admin`

- وقتی وارد `/admin` بشی، اگه لاگین نکرده باشی می‌ره سراغ `/admin/login` و ازت **همون مقدار `ADMIN_TOKEN`** رو می‌خواد (نه رمز جدا؛ همون متغیر محیطی که توی مرحله‌ی قبل ست کردی).
- بعد از لاگین، یک کوکی امن (`httpOnly`) ست می‌شه و تا ۷ روز لاگین می‌مونی.
- **صفحه‌ی Messages** (`/admin`): لیست همه‌ی پیام‌هایی که از فرم تماس سایت ارسال شدن (نام، ایمیل، بودجه، متن پیام، تاریخ).
- **صفحه‌ی Projects** (`/admin/projects`): لیست پروژه‌های Work + دکمه‌ی **Add project** برای اضافه‌کردن پروژه‌ی جدید (هر دو زبان، دسته‌بندی، سال، ترتیب نمایش، لینک عکس کاور، وضعیت انتشار)، و برای هر پروژه دکمه‌های **Edit** و **Delete**. هر تغییری مستقیم روی همون دیتابیسی می‌ره که صفحه‌ی عمومی Work ازش می‌خونه.

> این یک احراز هویت ساده با یک توکن مشترکه، نه یک سیستم کاربر/رمز کامل — برای یک سایت پرتفولیوی تک‌نفره کافیه، ولی اگه بعداً خواستی سطح امنیتش بالاتر بره (مثلاً چند ادمین، رمز جدا)، باید یک لایه‌ی احراز هویت واقعی (مثل NextAuth) روش اضافه بشه.

اگه خواستی مستقیم به خود دیتابیس هم نگاه کنی (مثلاً برای دیباگ)، همیشه می‌تونی:

```bash
npx prisma studio
```

## ۵) جایی که طراحی بصری رو عوض می‌کنی

- **رنگ‌ها:** `src/app/globals.css` → متغیرهای بالای فایل (`--color-bg`, `--color-fg`, `--color-accent`, ...).
- **فونت‌ها:** `src/app/[locale]/layout.tsx` → فونت‌های `next/font/google` (فعلاً Vazirmatn برای فارسی و Space Grotesk/Inter برای انگلیسی؛ می‌تونی با فونت اختصاصی خودت جایگزین کنی).
- **متن‌ها:** `src/lib/dictionaries/fa.ts` و `src/lib/dictionaries/en.ts` — همه‌ی متن‌های سایت اینجاست، تغییرش نیازی به لمس کامپوننت‌ها نداره.
- **لوگو/تصاویر:** هر جا فعلاً فقط متن یا جای خالیه (مثل `coverImage` پروژه‌ها)، بعداً می‌تونی عکس واقعی جایگزین کنی — کامپوننت‌ها آماده گرفتن URL عکس هستن.

## نکته درباره‌ی هزینه Railway

Railway بر اساس مصرف واقعی (ساعت اجرا/رم) شارژ می‌کنه و یک اعتبار رایگان ماهانه محدود می‌ده؛ برای یک سایت معرفی با ترافیک کم معمولاً همون اعتبار کافیه، ولی دیتابیس رو عمداً جدا (روی Neon) گذاشتیم که همیشه رایگان بمونه، حتی اگه اعتبار Railway تموم بشه یا بخوای هاست سایت رو عوض کنی.
